## 🧠 Justification stratégique keyword par keyword

### 1. `thriller psychologique francais` (32 chars)

**Pourquoi** : C'est la **porte d'entrée principale** de ta catégorie. Toute lectrice qui cherche un thriller FR tape ce type de requête. Volume de recherche élevé, concurrence forte mais indexation **gratuite** si tu mets ce KW en backend.

**Pourquoi pas "thriller psychologique" seul** : Trop concurrentiel, dominé par les bestsellers US. Le mot "français" te range dans une sous-niche moins saturée mais **acheteuse** (les lectrices FR veulent lire en français, pas de traduction).

### 2. `sœur jumelle disparition secret` (29 chars)

**Pourquoi** : C'est **ton concept signature** : sœur jumelle + disparition + secret. Ce KW cible exactement l'intrigue. Aucune concurrence directe sur Amazon FR — c'est ta **niche à zéro**.

**Pourquoi pas "jumelles thriller"** : Trop générique, dilué. L'expression longue "sœur jumelle disparition secret" matche l'intention exacte d'une lectrice qui veut **ce type d'histoire**.

### 3. `polar breton atmosphere` (23 chars)

**Pourquoi** : Le **cadre Bretagne** est un différenciateur vs la concurrence générique parisienne. Beaucoup de lectrices FR cherchent **des polars en région** (Bretagne, Normandie, Provence) pour l'évasion + l'atmosphère.

**Pourquoi "atmosphere" sans accent** : Amazon Ads ignore les accents en backend — écrire "atmospher" fonctionnerait aussi mais "atmosphere" reste l'orthographe la plus cherchée.

### 4. `thriller double identite` (24 chars)

**Pourquoi** : Concept universel et bankable. "Double identité" est un **terme-aimant** dans le thriller (genre "The Double", "Us", thrillers de sosies). Les lectrices qui tapent ça cherchent **exactement ton livre**.

**Pourquoi pas "sosie"** : Trop littéraire, sous-employé en search Amazon. "Double identité" est la formulation dominante.

### 5. `polar court page turner` (23 chars)

**Pourquoi** : Cible les lectrices **pressées / ADD / modernes** qui veulent un format court mais intense. Ton format 60K mots = 2-3 soirs est un **argument de vente** qu'il faut indexer.

**Pourquoi "polar court" et pas "roman court"** : "Polar" est plus bankable que "roman" en recherche thriller.

### 6. `enlevement enfants famille` (25 chars)

**Pourquoi** : **Trigger émotionnel massif** — la peur qu'on enlève un enfant, ou que notre famille nous cache quelque chose. C'est le **VOC racine universel** des thrillers psychologiques familiaux. Très fort en volume de recherche.

**Pourquoi pas "enlevement enfant"** : Le pluriel "enfants" matche mieux le search behavior Amazon FR (les lectrices tapent souvent au pluriel).

### 7. `roman suspense debut haletant` (30 chars)

**Pourquoi** : **L'objection #1** des acheteuses Kindle est "est-ce que ça démarre vite ?" Ce KW cible **l'intention de vérification** — la lectrice veut savoir si ton incipit est haletant (et il l'est : lettre bleue + appel hôpital le jour même).

**Pourquoi "debut haletant"** : C'est la formulation exacte que les lectrices tapent dans la barre Amazon (validé par mes années d'observation des Amazon Ads FR).
