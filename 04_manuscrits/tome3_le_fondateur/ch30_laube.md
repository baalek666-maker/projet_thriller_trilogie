# CHAPITRE 30 — L'aube

Le 17 août. Cinq heures du matin.

Le téléphone sonne. Le brigadier.

— Clémence. On entre à six heures. Trente-deux hommes. Deux colonnes — Quimper et Pau. Juge d'instruction en véhicule protégé. Hélène Doré avec eux.

— Denise ?

— Prévenue. Elle a le carnet.

— Auguste ?

— Dort. Le moniteur cardiaque est actif. Le gardien est en bas. Auguste ne sait rien.

— Alors on y est.

— On y est.

Je raccroche. Six heures. La perquisition de Tursan. L'arrestation d'Auguste. La fin.

Je ne réveille personne. Je m'assois dans le salon, dans le noir. Le soleil n'est pas levé. Les oiseaux ne chantent pas encore. La maison respire — Inès, Malo, Adam, mes parents, Charlotte, Clodomira — tous endormis, tous inconscients de ce qui se passe dans les Landes.

Cinq heures trente. Le soleil point. L'horizon rougit. Un autre jour.

Cinq heures quarante-cinq. Mon téléphone vibre. Image de la caméra de surveillance du domaine de Tursan — installée par les gendarmes trois jours plus tôt, en douce. Les portails. Les pins. L'allée de gravier. La maison.

Cinq heures cinquante-cinq. Les portails s'ouvrent. Pas de bruit. Mécaniques. Les deux colonnes entrent. Véhicules sombres, sans gyrophares. Trente-deux gendarmes en tenue. Le juge d'instruction. Hélène Doré.

Six heures. Les véhicules s'arrêtent devant la maison. Les gendarmes descendent. Le brigadier frappe à la porte. Le gardien ouvre.

L'image est muette. Je ne sais pas ce qu'ils disent. Mais je vois. Les gendarmes entrent. Le gardien lève les mains. Le brigadier monte l'escalier.

Auguste dort au rez-de-chaussée, dans la chambre médicalisée. Le brigadier ouvre la porte.

Auguste est réveillé. Assis dans son lit. Le moniteur cardiaque bipe. La canne est contre la table de nuit. Le chapeau est sur le pupitre.

Auguste sourit.

Le brigadier parle. Auguste écoute. Auguste hoche la tête. Auguste ne résiste pas. Auguste lève les poignets — fines, osseuses, translucides — pour les menottes. Le brigadier hésite. Le juge intervient. Les menottes sont mises.

Denise apparaît. Elle descend l'escalier. Elle tient le carnet — le carnet d'Auguste, le carnet de 1948, celui qui dit *la science n'a pas besoin de deux fondateurs*. Elle le donne au brigadier. Le brigadier le met dans une enveloppe. Preuve.

Les gendarmes fouillent. Le laboratoire est scellé. Les bacs à échantillons sont saisis. Les carnets d'Yvonne sont saisis. Les fichiers informatiques sont copiés. Les disques durs, les serveurs, les archives.

Auguste est sorti de la maison. En fauteuil roulant. Menotté. Le chapeau sur la tête. La canne sur les genoux. Il sourit. Toujours.

Le fauteuil roule dans l'allée de gravier. Les pins. Le ciel bleu. Les Landes.

Auguste est mis dans un véhicule. La porte se ferme. Le véhicule démarre.

Auguste Le Gac, cent quatre ans, fondateur de la chaîne, architecte de Transit, voleur du travail d'Yvonne, acheteur d'enfants, menace pour sa famille — Auguste est arrêté.

Six heures vingt-deux.

Mon téléphone vibre. Hélène.

— Clémence.

— Oui.

— C'est fait.

— Auguste ?

— En garde à vue. transféré à Pau. Centre hospitalier. Aile sécurisée. Il sera auditionné demain.

— Le carnet ?

— Saisi. Lu. Concluant. Les mots de 1948 et 1952 — confirmés. La main d'Auguste — confirmée. L'expertise graphologique prendra une semaine, mais le juge considère que c'est suffisant pour inculper.

— Inculpé de quoi ?

— Menace de mort. Trafic de substance humaine. Exercice illégal de la biologie. Association de malfaiteurs. Tentative d'enlèvement de mineur. Complicité de Transit dans les années 50 à 80.

— Transit ?

— Les archives de Tursan contiennent les registres. Les 48 sujets. Les noms. Les dates. Les acheteurs. Tout est là. Auguste a tout gardé. Comme un trophée. Comme un catalogue.

— Les 48.

— Les 48. Les chaînons. Les enfants vendus par Kervadec et achetés par Auguste. Les familles. Les destins. Les vies brisées. Tout est dans les archives.

— On pourra les retrouver ? Les chaînons ? Les familles ?

— C'est l'objectif. Le juge a ouvert une information judiciaire pour identifier les 48 sujets. Le fichier ADN sera croisé avec les bases existantes. On retrouvera les descendants. On les informera. On les soignera.

— Soigner ?

— Le sérum de Lucie. Le sérum universel d'Adam. Tout sera partagé. Sans brevet. Sans GenePlus. Le juge a saisi les formules. Elles seront publiées. En open source. Pour tout le monde.

— Open source.

— Open source. C'est la condition du juge. Le sang d'Adam a été donné pour sauver — pas pour être vendu. La formule appartient aux chaînons. Pas à Auguste. Pas à GenePlus. Aux chaînons.

Je ne dis rien. Les larmes coulent. Encore. Toujours. Mais cette fois, ce ne sont pas des larmes de peur. De soulagement. De fin. De commencement.

Les 48 seront retrouvés. Les 48 seront soignés. Les 48 auront une vie. Comme Malo. Comme Adam. Comme Lucie. Comme Camille. Comme Charlotte. Comme moi.

La chaîne se défait. Tube par tube. Sérum par sérum. Vie par vie.

— Hélène.

— Oui ?

— Merci.

— Ne me remercie pas. C'est mon travail.

— Merci quand même.

Elle raccroche. Le soleil est levé sur Pont-l'Abbé. Les oiseaux chantent. La maison s'éveille. Inès descend. Malo descend. Adam descend. Mes parents descend. Charlotte descend.

— Alors ? dit Inès.

— C'est fait, dis-je. Auguste est arrêté.

Le silence. Puis les cris. Les larmes. Les rires. Les bras. Les baisers. Les enfants qui courent. Les grands-parents qui pleurent. Charlotte qui sourit — un vrai sourire, le premier depuis des mois.

Et moi, je reste debout, au milieu du salon, au milieu de ma famille, et je sens quelque chose que je n'avais pas senti depuis le début. Depuis Kerfany. Depuis le manoir. Depuis le sac. Depuis le sang.

La paix.

La paix, enfin.

La dernière chaîne vient de céder.
